# VELOCITY MOTO 4.0

แอป Android 8.0 ขึ้นไป วัดความเร็ว GPS แบบออฟไลน์ พร้อมหน้าปัดที่ปัดเปลี่ยนได้และเสียงเครื่องยนต์สังเคราะห์ตามความเร็ว

## เริ่มใช้งาน

1. ติดตั้ง `dist/Velocity-Moto-4.0-debug.apk` ทับรุ่นเดิมได้เมื่อใช้ลายเซ็นเดียวกัน
2. แตะหน้าปัด เปิดหมวด **เริ่ม** แล้วกด **เริ่มจับความเร็ว GPS** อนุญาตตำแหน่งแบบแม่นยำขณะใช้แอป
3. ปัดซ้ายไปหน้าปัดถัดไป ปัดขวาย้อนกลับ วนได้ 15 ตำแหน่ง: Focus / Orbit / Circuit และหน้าปัดรถ 12 รุ่น
4. แตะเพื่อเปิดเมนู ปัดแนวตั้งจะไม่เปิดเมนูหรือเปลี่ยนหน้าปัด ปิดการปัดและแรงสั่นตอบรับได้ที่ **หน้าปัด**
5. กดพักหรือจบทริปจากหมวดเริ่ม เมนูปิดด้วยปุ่ม **ปิด ×** หรือ Back

## เมนูที่แยกเป็นหมวด

- **เริ่ม** — เริ่ม/พัก GPS, เปลี่ยนหน้าปัด, ปิดเสียงด่วน, โหมดความเร็วล้วน, เดโม และจบทริป
- **หน้าปัด** — รูปแบบ, รุ่นรถ, แสดง/ซ่อนเกียร์ รอบ และสถิติ, การปัด, ธีม 24 แบบ
- **เสียง** — สวิตช์หลักและระดับเสียง, เครื่องยนต์, ท่อ/เบส, เกียร์/รอบตก, จุดระเบิด และพรีเซ็ตเสียง
- **ทริป** — ประวัติ, รายละเอียดรอบ, ส่งออก CSV/GPX และเครื่องมือเดินทาง
- **ระบบ** — แนวหน้าจอ, หน่วย, ความสว่าง, เปิดจอค้าง, แอนิเมชัน, GPS/การเตือน และเครดิต

หน้ารายละเอียดมีปุ่มกลับไปหมวดต้นทาง รายการไม่ถูกรวมไว้ในหน้าตั้งค่ายาวหน้าเดียว

## ภาพและการปัด

มีธีมขาวเงา Pearl Gloss, ดำเงา Obsidian Gloss, Cloud Silver และ Moon Violet รวมกับสีเดิมเป็น 24 ธีม เมนูและกล่องเลือกปรับตามโหมดสว่าง/มืด

การปัดแยกจากการแตะ ใช้ระยะและทิศทาง ไม่บังคับว่าต้องสะบัดเร็ว เปลี่ยนข้อมูลใน View เดิมโดยไม่สร้างหน้าจอใหม่ จึงไม่รีเซ็ตนาฬิกาแอนิเมชัน และยกเลิก toast เก่าก่อนแสดงชื่อใหม่เพื่อไม่สะสมข้อความเมื่อปัดเร็ว

เมื่อซ่อนเกียร์และ RPM ในหน้าปัดรถ ชื่อรุ่นและลักษณะการแสดงความเร็วยังคงเปลี่ยนตามรุ่น ไม่เหลือครึ่งจอว่างแทนมาตรวัดที่ซ่อน

ใช้ Choreographer ตาม VSync และขอรีเฟรชเรตสูงสุดที่อุปกรณ์รองรับ งานภาพคงที่ถูกแคช การวัด FPS จริงขึ้นกับจอ GPU โหมดประหยัดพลังงาน และอุณหภูมิ ไม่รับประกัน 60/90/120 FPS บนอุปกรณ์ทุกเครื่อง

## เสียงและระบบเกียร์จำลอง

มี 8 คาแรกเตอร์เครื่องยนต์ × 12 ท่อ = 96 ชุด ปรับน้ำหนักเบส รายละเอียดเสียง และระดับเสียงแยกได้ มีท่อใหม่ Velvet bass, Touring deep, Dual chamber และ Long muffler พร้อมพรีเซ็ตนุ่มลึก/เงียบอุ่น/สปอร์ต/สนาม

- **เข้าเกียร์อัตโนมัติ** มี hysteresis และช่วงหน่วงเพื่อลดการสลับเกียร์จากค่า GPS ที่แกว่ง
- **รอบตก** เปิด/ปิดและปรับน้ำหนักได้ ปิดเพื่อให้รอบไหลต่อเนื่อง
- **จังหวะคั่นเกียร์** เปิด/ปิดการลดเสียงสั้น ๆ ระหว่างเปลี่ยนเกียร์
- **จุดระเบิดเบา ๆ** ปิดเป็นค่าเริ่มต้น เกิดเฉพาะเมื่อผ่อนจากรอบสูง มีช่วงพักระหว่างเอฟเฟกต์ ความเข้ม 0–30%
- **เริ่มเครื่องแบบนุ่ม** ค่อย ๆ รับระดับเสียงช่วงเริ่ม ไม่ใช่เสียงสตาร์ทที่บันทึกจากรถจริง

เสียง เกียร์ และรอบทั้งหมดเป็นการสังเคราะห์เพื่อความบันเทิงจากความเร็ว GPS **ไม่มีการเชื่อมต่อ ECU/OBD** และไม่ใช่ไฟล์เสียงแท้ของผู้ผลิต โทนเบสต่ำที่ได้ยินขึ้นกับลำโพง/หูฟัง

เสียงทำงานเมื่อเปิดสวิตช์และเริ่ม GPS ที่มีข้อมูลสด หรือเปิด DEMO หยุดเมื่อพัก GPS ขาดหาย ออกจากแอป หรือเสีย Audio focus ระดับเสียงใช้ร่วมกับ Media volume ของ Android

## GPS ทริป และการส่งออก

- ขอ GPS ทุก 500 ms; อัตรารับข้อมูลจริงขึ้นกับอุปกรณ์และสัญญาณ แยกจากอัตราวาดหน้าจอ
- กรองพิกัดอายุเกิน 5 วินาที ความแม่นยำเกิน 35 เมตร และค่าความเร็วที่ความคลาดเคลื่อนเกิน 3 m/s
- สัญญาณขาดเกิน 5 วินาทีจะล้างความเร็วปัจจุบันและหยุดเสียง ไม่ประมาณความเร็วแทนสัญญาณที่หาย
- GPS ทำงานเฉพาะขณะเปิดแอป ออกจากแอป/ล็อกหน้าจอจะพักทริป ไม่มี background service
- ประวัติสูงสุด 100 ทริป; manual LAP สูงสุด 100 รอบ/ทริป ไม่นับเวลาพัก
- เส้นทางออฟไลน์ทุกอย่างน้อย 5 วินาที สูงสุด 4,000 จุด และกราฟความเร็วล่าสุด 120 ตัวอย่าง
- GPX ของทริปปัจจุบันหรือที่เพิ่งจบ, CSV ประวัติทริป ผ่านตัวเลือกไฟล์ Android เปิดตัวเลือกบันทึกจะพักทริป
- CSV ใช้หน่วย SI ชัดเจน (`distance_m`, `duration_s`, `max_mps`, `average_mps`) และวันที่ UTC

ข้อมูลอยู่บนเครื่อง ไม่มีบัญชีหรือการส่งตำแหน่งไปเซิร์ฟเวอร์ การทดสอบบนมือถือจริงและสภาพขี่จริงยังไม่ครอบคลุม

## Build / ทดสอบ

Java 17 หรือ 21, Android SDK Platform 34; ตั้ง `ANDROID_HOME` หรือ `local.properties` ให้ตรง SDK ของเครื่อง

```powershell
.\gradlew.bat assembleDebug lintDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk` เป็น debug build สำหรับติดตั้งทดสอบ การเผยแพร่ต้องสร้าง signed release/AAB ของผู้เผยแพร่

ทดสอบบน emulator แบบแยก ข้อมูลทริปทดสอบปัจจุบันจะถูกรีเซ็ต:

```powershell
.\gradlew.bat assembleDebugAndroidTest
adb install -r app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
adb shell am instrument -w com.onesecondx.velocity.test/com.onesecondx.velocity.V4Verification
```

ทดสอบ DSP โดยไม่ใช้ Android:

```powershell
javac -encoding UTF-8 -d build/synth-tests app/src/main/java/com/onesecondx/velocity/DriveModel.java app/src/main/java/com/onesecondx/velocity/EngineSynth.java tests/V4SoundCheck.java
java -cp build/synth-tests V4SoundCheck
```
